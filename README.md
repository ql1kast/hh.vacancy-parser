# HH Vacancy Parser

Парсер вакансий с hh.ru. Собирает данные о вакансиях, анализирует зарплаты и навыки.

## Что делает
- Собирает вакансии с hh.ru.
- Сохраняет данные в JSON.
- Считает среднюю, минимальную и максимальную зарплату.
- Собирает навыки из всех вакансий.
- Формирует топ-15 самых востребованных навыков.

## Как запустить 
1. Установить зависимости
```
    pip install requests
```
2. Запустить
```
    python hh_api.py
```

## Результаты
- `vacancies.json` - все вакансии.
- `skills.json` - все навыки из вакансий.
- `top_skills.json` - топ-15 самых востребованных навыков.

## Пример вывода
```
    Сохранено в vacancies.json
    Всего вакансий: 51
    Вакансий с зарплатой: 15
    Средняя зарплата: 202234
    Максимум: 450000
    Минимум: 37500
    Готово! Собрано навыков: 231

    Сохранено в skills.json
    Топ-15 сохранен в top_skills.json
```
